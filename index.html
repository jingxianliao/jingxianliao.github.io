Selected algorithms

Each method addresses a different part of the modeling and control problem.

AeroKANLearning architecture

Physics-embedded Kolmogorov–Arnold networks

An analytical lift prior is part of each edge function. A trainable residual corrects the prior, and the shared transition parameter can be estimated from data without a separate physics-loss weight.

EvidenceLift-coefficient predictions are evaluated against wind-tunnel measurements for both symmetric and cambered airfoils.
AeroKAN paper
allocKANAdaptive control

Online allocation with Lyapunov stability analysis

A KAN adapts control allocation as actuator effectiveness changes. Bounds on parameter sensitivity enter the composite Lyapunov analysis to characterize conditions for uniformly ultimately bounded behavior.

EvidenceApproximately parameter-matched offline comparison and closed-loop fault simulations.
allocKAN paper

Convertible aircraft

During conversion between hover and forward flight, aerodynamic regimes and actuator effectiveness change together. My work addresses lift prediction and adaptive control allocation across that transition.

Embodied intelligence

Current direction: compact robot dynamics models for control. A related patent application addresses KAN edge selection under a model budget and robot end-effector position prediction.
